# How I work

I originally just wanted to compare two mathematics textbooks and build a plan for my class from them. Four weeks before the new school year, I opened ChatGPT: Could AI help me with this? It did not stop with that one question.

Those first experiments grew into worksheets, YAML files, learning workshops, libraries, and local tools.

Not because I had a grand plan.

Not because I love order for order’s sake.

What fascinates me is the moment when a structure suddenly makes something possible: A YAML file can make the logic of teaching visible. A library can keep months of work from disappearing into old chats. A didactic matrix can turn individual tasks into a learning space.

Most of the time, it starts with a question: Can AI do this? Then I build a first solution, test it, take it apart again, and often discover a larger question behind it.

And sometimes I ask myself questions such as: What could metacognitive work with AI look like? Or: How can a project remain capable of action when every LLM call starts from zero again?

This GitHub profile shows part of that workshop. Not everything is finished. Not everything worked. But every project has shown me something about how people and AI can work together without the human letting go of the direction.
